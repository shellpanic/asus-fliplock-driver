# Maintained ASUS fliplock / NumberPad fork

This public fork preserves its original fliplock history and adds a separately
attributed optional [NumberPad component](numberpad/README.md). The maintained
version target is **2.0.0**, independent of imported NumberPad **v7.3.0 + two
recovery fixes**. Exact hardware mapping is provisional; hardware and graphical
acceptance are pending, not claims of working support.

[Origins and licenses](numberpad/ORIGINS.md) · [Validation](numberpad/VALIDATION.md)

Legacy fliplock code and configuration remain in their original paths. They are
inactive unless separately installed. The old installers are historical code:
**do not run them**. They include broad system changes/telemetry inappropriate
for the reviewed setup. The NumberPad staged installer never invokes them and
does not install the legacy service. Keyboard backlights and privacy indicators
are outside the new component. [Legacy upstream documentation](LEGACY-FLIPLOCK.md).
